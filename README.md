# Weekly Planner

一个简洁的桌面周计划任务管理应用。

## 功能

- 周计划任务管理
- 本地数据存储
- 简洁直观的桌面应用界面

## 下载使用

前往 [Releases](https://github.com/qiqi1030/weekly-planer/releases) 页面，下载最新版本的 `.exe` 文件，双击运行即可。

## 开发运行

如果你需要查看或修改源码：

```bash
# 克隆仓库
git clone https://github.com/qiqi1030/weekly-planer.git

# 安装依赖
npm install

# 启动应用
npm start
